Aviso de privacidad

ReportaCalle es un proyecto ciudadano, sin fines de lucro, para que las personas de San José Iturbide, Guanajuato, informen problemas de la calle. Este aviso explica qué datos se recogen y para qué.

Quién es responsable

El responsable del proyecto ReportaCalle (persona que administra esta página). Sustituye esta frase por tu nombre cuando publiques el aviso definitivo.

Qué datos se recogen

  • Tipo de problema, descripción y una o varias fotos.
  • Ubicación del lugar (latitud y longitud), tomada del GPS del teléfono o del pin que coloques en el mapa.
  • Nombre y teléfono o correo, solo si tú los escribes. El contacto es opcional.
  • Si marcas «Reportar de forma anónima», no guardamos nombre ni contacto aunque los hayas escrito.

Para qué se usan

  • Registrar el reporte y darte un folio para que puedas seguirlo.
  • Permitir que el responsable visite el lugar, tome fotos de inspección y anote medidas y una recomendación de reparación.
  • Enviar esa información al municipio de San José Iturbide para que pueda atender el problema.

Con quién se comparten

Las fotos, la ubicación, la descripción, las medidas y la recomendación se comparten con el municipio. El mapa público y la página de seguimiento muestran el problema y su avance, pero no tu nombre, teléfono ni correo.

No vendemos ni rentamos datos. No los usamos para publicidad.

Cuánto tiempo se conservan

Se conservan mientras el reporte siga siendo útil para su atención o hasta que pidas que se borre.

Cómo pedir que se borre un reporte

Escribe al responsable de ReportaCalle, indica el folio (por ejemplo RC-0001) y pide la eliminación. Cuando definas el correo de contacto del proyecto, ponlo en este párrafo. Si el reporte ya se envió al municipio, también se le pedirá que deje de usarlo, aunque no podemos controlar las copias que el municipio ya tenga.

Seguridad

El panel de administración está protegido con contraseña. Aun así, ninguna página en internet es infalible: no envíes por este medio datos que no quieras que vea el municipio junto con el reporte.

Cambios

Si este aviso cambia, se publicará la versión nueva en esta misma página.
